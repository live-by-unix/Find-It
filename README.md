## Find-It! When you need to find it.    

**This README covers usage, tech stack, PWA installation, and licensing** 

## Usage   
The app is pretty explanatory, but for voice and type mode you need to speak in this format:   
<thing> in <place>, or something similar, so if I have a jar and want it on the table, I would say "jar on table".  
For type mode, you would type the same thing.   

## Tech Stack 
Regex pattern for location and thing, no framework HTML/CSS/JS, and a lighting fast speech engine, along with INDEXED@DB localstorage for storing all.   

## PWA installation   
PWA installation is fully supported.
